# UE Game Launcher 启动预检器

## 最简单用法（只要记这一个）

1. 找到本目录里的 **`一键部署到项目.bat`**
2. 把 UE 打包出来的 **`Windows` 文件夹拖到它上面**
3. 按提示输入内存/显存门槛（回车用默认，`0`=不检查）
4. 等到提示「完成」，去目标目录 **双击项目名.exe**（原 UE 启动 exe 已被替换）

脚本会自动：缺 exe 就编译、复制文件、填好游戏路径和硬件门槛，并删掉原启动 exe、把预检器改名为项目名。

详细说明见：`启动预检器使用说明.md` / `启动预检器使用说明.docx`

---

### 换图标（偶尔才做）

1. 用新图标覆盖本目录 `logo.ico`
2. 再拖一次 `Windows` 到 `一键部署到项目.bat`（会自动重编）
3. 若图标还是旧的，双击 `clear-icon-cache.bat`

### 只改内存/文案（不用重编）

编辑目标目录里的 `launcher.ini`，保存后再运行 `launcher.exe`。

---

## 其他脚本（一般不用）

| 文件 | 说明 |
|------|------|
| `一键部署到项目.bat` | **日常唯一入口**（询问内存/显存） |
| `build.bat` | 仅手动编译 |
| `deploy.bat` | 仅手动部署 |
| `clear-icon-cache.bat` | 清图标缓存 |

## 功能摘要

环境检查（内存/显存/冲突进程）、自动装 VC++/DX11、防重开、配置全在 `launcher.ini`。
